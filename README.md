# Tic-Tac-Toe

A responsive two-player Tic-Tac-Toe game built using HTML, CSS and JavaScript.

## Live Demo

[Play the game](https://tic-tac-toe-game-gg.netlify.app/?utm_source=chatgpt.com)

## Features

* Two-player gameplay on the same device
* Win detection for both players
* Draw detection
* Win counter for Player 1, Player 2 and draws
* Responsive design
* Animations

## Technologies Used

* HTML
* CSS
* JavaScript

## Note

This was built as a learning project while practicing JavaScript, DOM manipulation and basic game logic.
